# 🚀 Windows 下 Python 虚拟环境与 MarkItDown 极简配置指南
## 本工具来源：https://github.com/microsoft/markitdown

## 📌 前置准备

在开始之前，请确保你的编辑器（如 VS Code 或 WebStorm）的终端路径已经处于你的项目文件夹下。
例如：`PS D:\博客代码\my-blog>`

---

## 🛠️ 操作步骤

### 第一步：创建“独立小房间”（生成虚拟环境）

在项目文件夹的终端中，运行以下命令来创建一个名为 `.venv` 的虚拟环境文件夹：

```powershell
python -m venv .venv
```
 * ⚠️ ️**避坑提示**：
如果系统报错提示“找不到路径”或直接弹出了微软应用商店，说明你的 python 命令被 Windows 的假别名拦截了。请使用你电脑上真正的 Python 绝对路径来代替，例如：
C:\Users\你的用户名\AppData\Local\Python\bin\python.exe -m venv .venv

 ###  第二步：走进“小房间”（激活虚拟环境）
每次重新打开项目准备写代码或运行工具前，必须执行这一步：
```powershell
.\.venv\Scripts\activate
```
* ✅ **成功标志**：
执行完毕后，注意观察终端最左侧。如果出现了一个绿色的 (.venv)，说明你已经成功进入了虚拟环境！
例如：(.venv) PS D:\博客代码\my-blog>

###  第三步：给房间添置“全能工具”（安装 MarkItDown）
在确保终端带有 (.venv) 前缀的状态下，运行以下命令进行安装：(all就是MarkItDown 能处理所有文件格式的依赖包，此步骤每个新项目只需执行一次)
```powershell
pip install "markitdown[all]"
```

### 第四步：开始施展魔法（文件转换）
将你需要转换的文档（如 Word、PDF）放入当前的项目文件夹中，然后运行命令：
```powershell
markitdown 你的文件名.docx > output.md
```
执行完毕后，打开自动生成的 output.md 文件，里面就是干净标准的 Markdown 文本啦！
